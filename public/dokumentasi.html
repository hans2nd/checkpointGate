Dokumentasi Sistem Checkpoint GIIC

Aplikasi Checkpoint GIIC adalah sistem manajemen antrean dan loading/unloading kendaraan di area pergudangan PT. Pangan Lestari. Sistem ini dirancang untuk mencatat, melacak, dan memonitor seluruh aktivitas kendaraan mulai dari kedatangan, proses loading, hingga penyerahan dokumen secara real-time.

Akses Mobile: Aplikasi ini mendukung akses melalui Web Browser untuk admin/supervisor dan Mobile App untuk operator di lapangan.

Silakan unduh dan install APK di perangkat Android Anda.

1. Dashboard

Dashboard adalah halaman utama setelah pengguna berhasil login. Halaman ini memberikan ringkasan (summary) data harian dan statistik performa gudang secara keseluruhan.

Fitur & Informasi Utama:

  • Statistik Harian: Menampilkan jumlah kendaraan yang terdaftar (Total), sedang parkir, sedang proses loading, dan yang sudah selesai hari ini.
  • Grafik Aktivitas: Visualisasi data inbound/outbound berdasarkan jenis barang (Frozen/Dry/Chilled).
  • Shortcut Akses: Tombol cepat untuk menuju menu Data Checkpoint atau Live Monitoring.

2. Data Checkpoint

Modul ini adalah urat nadi aplikasi, digunakan untuk merekam seluruh jejak perjalanan kendaraan sejak tiba di lokasi hingga meninggalkan area gudang. Modul ini dilengkapi dengan validasi hak akses untuk memastikan integritas data.

Alur Proses (Workflow) Kendaraan:

1. Pendaftaran (Entry)

Kendaraan baru tiba. Admin Inbound/Outbound mendaftarkan No. Polisi, Vendor, Supir, Jenis Kendaraan, dan Jenis Barang (Inbound/Outbound). Status awal biasanya berupa antrean (menunggu gate kosong).

2. Penerimaan Dokumen (Assign Gate)

Admin menentukan Gate (misal F-1 atau D-2) berdasarkan Gate yang diisi oleh Operator pada form Gate fisik dan menekan tombol "Terima Dokumen" (waktu_penerimaan_dokumen). Status kendaraan berubah menjadi ASSIGN / START.

3. Mulai Loading (Start Loading)

Operator gudang menekan tombol "Start Loading" (waktu_start). Waktu mulai dicatat dan status berubah menjadi ON LOADING. Sistem mencatat siapa user yang memulai.

4. Selesai Loading (Finish)

Operator menekan "End Loading" (waktu_end). Sistem otomatis menghitung durasi (End - Start). Status berubah menjadi FINISH. Catatan: Aksi ini dibatasi hanya bisa dilakukan oleh user yang melakukan "Start" (atau Supervisor).

5. Penyerahan Dokumen (Completed)

Admin Inbound/Outbound menyerahkan kembali surat jalan/dokumen ke supir (waktu_penyerahan_dokumen). Kendaraan dianggap selesai sepenuhnya dan akan hilang dari layar Live Monitoring.

Pembatalan (Cancelation Workflow)

Jika terjadi kesalahan, transaksi tidak dapat langsung dihapus. User harus menekan tombol "Request Cancel". Transaksi akan masuk ke status WAITING CANCEL. Supervisor/Admin kemudian harus melakukan "Approve Cancel" agar transaksi benar-benar dibatalkan.

3. Master Employee

Modul ini dirancang khusus untuk mempermudah akses login bagi pekerja lapangan (operator mobile) tanpa perlu menggunakan Email dan Password yang rumit. Sistem mengadopsi struktur Dual-Authentication.

Fungsi & Alur:

  • Manajemen Data: Admin mendata pekerja dengan memasukkan Employee ID, Nama, dan Role (Hak Akses).
  • Sinkronisasi User: Saat menambahkan Employee, terdapat opsi untuk otomatis membuatkannya akun "User Management" tersembunyi (Shadow User) agar sistem Role-Based Access Control (RBAC) tetap berjalan seragam.
  • Login Praktis:
    • Di Web Browser, pengguna dapat beralih ke tab "Employee ID" untuk login tanpa password.
    • Di Mobile App, seluruh pekerja diwajibkan login hanya menggunakan Employee ID demi kecepatan dan efisiensi di lapangan.

4. Live Monitoring

Modul ini didesain sebagai Dashboard Real-Time yang ditampilkan pada layar TV/Monitor besar di area operasional. Halaman ini melakukan refresh otomatis setiap 5 detik.

Struktur Layar (Carousel):

Layar akan bergeser otomatis (Slider) secara bergantian antara 2 tampilan utama:

📊 Slide 1: Summary & Average

  • Activity Summary: Tabel total parkir, penyerahan dokumen, on process, dan finish murni berdasarkan hari ini (H).
  • Average Time: Perbandingan rata-rata durasi loading hari ini (Today) vs bulan lalu (L.Month) berdasarkan tipe kendaraan. Terdapat indikator warna (Hijau=Lebih Cepat, Merah=Lebih Lambat).

🚪 Slide 2: Gate Grid Status

  • Menampilkan petak-petak Gate Frozen (F1-F16) dan Dry (D1-D11).
  • Hanya menampilkan gate yang sedang ada kendaraan aktif (Belum Completed).
  • Indikator Warna Durasi: Gate berubah warna (Hijau → Kuning → Merah) seiring berjalannya waktu loading untuk memberi peringatan visual jika ada keterlambatan.

💡 Fitur Auto-Scaling:

Live monitoring dirancang responsive. Jika ditekan tombol Fullscreen (atau `F11`), seluruh grid dan tabel akan memperbesar (zoom) otomatis menyesuaikan resolusi TV tanpa merusak susunan layout (Dynamic Scaling/Rem calculation).
