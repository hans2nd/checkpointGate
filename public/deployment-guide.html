01 Clone / Upload Source Code

bash# Via Git
git clone https://github.com/username/checkpoint-GIIC.git
cd checkpoint-GIIC

# Atau upload manual via cPanel File Manager / FTP

02 Install Dependency PHP (Composer)

bashcomposer install --optimize-autoloader --no-dev
ℹ️

Flag --no-dev menghilangkan dependency development (Breeze, Pint, PHPUnit, dll) agar lebih ringan di production.

03 Install & Build Asset Frontend (Vite)

bashnpm ci
npm run build

Perintah ini menghasilkan folder public/build/ berisi CSS & JS yang sudah di-compile dan minified.

💡

Setelah npm run build selesai, folder node_modules boleh dihapus di server untuk menghemat ruang disk.

04 Konfigurasi Environment (.env)

bashcp .env.example .env

Edit file .env sesuai dengan konfigurasi production:

envAPP_NAME="Checkpoint GIIC"
APP_ENV=production
APP_KEY=                          # generate di langkah berikutnya
APP_DEBUG=false                   # ⚠️ WAJIB false di production
APP_TIMEZONE=Asia/Jakarta
APP_URL=https://yourdomain.com

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=checkpoint_giic
DB_USERNAME=db_user
DB_PASSWORD=db_password_aman

SESSION_DRIVER=database
CACHE_STORE=database
QUEUE_CONNECTION=database

MAIL_MAILER=smtp
MAIL_HOST=smtp.example.com
MAIL_PORT=587
MAIL_USERNAME=your@email.com
MAIL_PASSWORD=email_password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS="noreply@yourdomain.com"
MAIL_FROM_NAME="${APP_NAME}"
🚨

Pastikan APP_DEBUG=false di production! Jika true, error detail akan terlihat oleh user dan bisa menjadi celah keamanan.

05 Generate Application Key

bashphp artisan key:generate

06 Buat Database & Jalankan Migrasi

bash# Buat database terlebih dahulu di MySQL:

📝

Flag --force diperlukan karena environment production secara default akan menolak migrasi tanpa konfirmasi.

09 Set Permission Storage & Cache

bashchmod -R 775 storage bootstrap/cache
chown -R www-data:www-data storage bootstrap/cache

Sesuaikan user www-data dengan user web server Anda (bisa apache, nginx, atau user lain).

10 Konfigurasi Web Server

Pastikan Document Root mengarah ke folder public/:

Apache
Nginx
cPanel
# httpd.conf atau VirtualHost
DocumentRoot /var/www/checkpoint-giic/public

<Directory "/var/www/checkpoint-giic/public">
    AllowOverride All
    Require all granted
</Directory>

.htaccess sudah tersedia di folder public/ dan akan otomatis menangani routing.

server {
    listen 80;
    server_name yourdomain.com;
    root /var/www/checkpoint-giic/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
# Opsi A: Symlink (Recommended)
ln -s /home/user/checkpoint-giic/public /home/user/public_html

# Opsi B: Upload semua file ke public_html,
# pindahkan isi public/ ke root public_html,
# lalu edit index.php untuk menyesuaikan path.

11 Buat Symbolic Link Storage

bashphp artisan storage:link

Membuat symlink public/storage → storage/app/public agar file upload bisa diakses publik.

🔄 Langkah Update di Production

Ketika ada update code baru, jalankan perintah berikut di server:

bash# 1. Pull code terbaru
git pull origin main

# 2. Install dependency baru (jika ada)
composer install --optimize-autoloader --no-dev

# 3. Rebuild asset (jika ada perubahan frontend)
npm ci && npm run build

# 4. Jalankan migrasi baru
php artisan migrate --force

# 5. Clear & rebuild cache
php artisan config:cache
php artisan route:cache
php artisan view:cache

# 6. (Opsional) Restart queue worker jika ada
php artisan queue:restart

🛡️ Tips Keamanan

  • Jangan expose file .env — pastikan web server hanya melayani folder public/
  • Backup database rutin sebelum update
  • Gunakan HTTPS — install SSL certificate (gratis via Let's Encrypt)
  • Update dependency secara berkala untuk patch keamanan
⚠️

Selalu backup database dan file sebelum melakukan update di production!
